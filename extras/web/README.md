# WAI-NET // ไหว้กูซะ

The web part of **hwAI ไหว้กูซะ**: leaderboards (โอกาสรอด, ไหว้สวยสุด, ไหว้เยอะสุด, ไหว้พระ, ติดต่อกัน, Hall of Shame),
the Hall of Fame, the odds of surviving an AI takeover with a bell-curve percentile, a TV mode for the booth, and the API the desktop app uploads to.

```bash
npm install && npm run dev     # http://localhost:3000, works offline with simulated data
```
