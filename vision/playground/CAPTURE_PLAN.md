# แผนเก็บท่าไหว้ (Capture plan)

ใช้กับ `recorder.html` เพื่อเก็บข้อมูลให้ครอบคลุมระดับ 0–3 หลายลักษณะ และให้คะแนนคุณภาพแต่ละรอบ
เป้าหมาย: ได้ข้อมูลที่แยกระดับได้จริง แล้วใช้คะแนนคุณภาพเลือกตัวอย่างที่ดีไปจูนโมเดล

## 1. ตั้งกล้องก่อนเริ่ม
- ตั้งกล้องให้เห็นตั้งแต่ศีรษะถึงสะโพก และมือทั้งสองข้างต้องอยู่ในเฟรมตลอดการไหว้
- ยืนห่างกล้องประมาณ 1–1.5 เมตร อย่าใกล้จนมือหลุดขอบ
- กด **C** ตอนยืนตรงมองกล้อง (จำค่าศีรษะปกติ) ทำทุกครั้งที่เปลี่ยนมุมหรือเปลี่ยนคน

## 2. ระดับและลักษณะที่ต้องเก็บ

| ระดับ | ท่า | ลักษณะที่ต้องครอบคลุม (variant) |
|---|---|---|
| 0 | ไม่ไหว้ (มือห้อย, เกา, โบกมือ, ปรบมือ, ท่าพนมแบบไม่ถึงอก) | front, tilt-left, tilt-right, hands-low, hands-high |
| 1 | พนมมืออยู่ระดับอก | front, tilt-left, tilt-right, far, close |
| 2 | ปลายนิ้วถึงจมูก | front, tilt-left, tilt-right, low-angle |
| 3 | นิ้วโป้งถึงหน้าผาก และก้มหัว | front, tilt-left, tilt-right, low-angle |

หมายเหตุ
- ระดับ 0 ต้องเก็บเยอะที่สุด เพราะถ้าโมเดลจับผิด จะเป็นการไหว้ให้ AI เองทุกครั้ง
- ระดับ 1–3 ให้ค้างท่าอย่างน้อย 1 วินาทีในแต่ละรอบ เพื่อให้ตัวกรองเห็นว่า "ผ่าน"
- "tilt-left/right" คือเอียงศีรษะหรือตัวไปทางซ้าย/ขวาประมาณ 15–20 องศา ไม่ใช่หมุนทั้งตัว

## 3. จำนวนรอบ (เป้าขั้นต่ำ)
- แต่ละ (ระดับ, ลักษณะ) อย่างน้อย **3 รอบ** ต่อคน
- ระดับ 0 อย่างน้อย 5 รอบต่อลักษณะ
- ถ้ามีเวลา เพิ่มคนที่สองอย่างน้อย 1 คน เพื่อกันโมเดลจำหน้าหรือรูปร่างของคนแรก

## 4. คะแนนคุณภาพ (1–5) ที่ใส่ในช่อง "คุณภาพ"

| คะแนน | ความหมาย |
|---|---|
| 5 | ท่าชัด มือแนบกัน อยู่ที่ระดับเป้าหมาย สมมาตร ค้างได้ ≥ 1 วินาที (ระดับ 3 ต้องก้มหัวเห็นชัด) |
| 4 | ชัดแต่มีเอียงหรือสูงต่ำเล็กน้อย |
| 3 | จำได้ว่าเป็นท่านั้น แต่ไม่สมมาตรหรือค้างสั้น |
| 2 | ท่าคล้ายแต่ไม่ถึงระดับเป้าหมาย (เช่น ควรเป็น 3 แต่ได้แค่ 2) |
| 1 | ไม่ชัด มือหลุดเฟรม หรือบังหน้า |

ระดับ 0 ให้คะแนน 5 ถ้าเป็นท่าที่ไม่ใช่ไหว้ชัดเจน และให้ 1–2 ถ้าเป็นท่าที่คล้ายไหว้มาก (เช่น พนมมือต่ำ)

## 5. ขั้นตอนต่อหนึ่งรอบ
1. เลือกระดับที่ปุ่มตัวเลข (0–3) และ variant ใน dropdown และคุณภาพ
2. กด **R** เริ่ม ทำท่าให้ค้างประมาณ 3 วินาที ปล่อย แล้วกด **R** หยุด
3. ดูตารางนับจำนวนที่หน้าจอ ว่าช่องไหนยังขาด
4. ทำจนครบ แล้วกด "ดาวน์โหลด JSON" ตั้งชื่อไฟล์ให้มีชื่อคนและวันที่

## 6. ใช้คะแนนอย่างไร
- ใส่คะแนนลงในทุกเฟรมของรอบนั้น (ตอนนี้ค่า quality ถูกบันทึกทุกเฟรมที่บันทึกอยู่)
- ตอนจูนโมเดล ให้ใช้เฉพาะเฟรมคุณภาพ 4–5 เป็นตัวอย่างบวก และดูเฟรมคุณภาพ 1–2 แยกเป็นกรณีที่โมเดลควรไม่ผ่าน
- ถ้าโมเดลให้ระดับต่ำกว่าคะแนนคุณภาพมาก (เช่น คุณภาพ 5 แต่ได้ 0) ให้บันทึกเป็นกรณีแก้ไข
