# hwAI Web Guard (ส่วนขยายเบราว์เซอร์)

ส่วนขยาย Chromium (Manifest V3) ที่ตรวจจับการกดส่งพรอมต์บน claude.ai, chatgpt.com (รวม chat.openai.com) และ gemini.google.com แล้วแจ้ง hwAI daemon บนเครื่อง (`127.0.0.1:7777`) ใช้ได้กับ Arc, Chrome, Edge, Brave

## ติดตั้ง (Arc / Chrome)
1. เปิด hwAI ให้ daemon ทำงานอยู่
2. เปิด `chrome://extensions` (ใน Arc พิมพ์ที่ address bar ได้เช่นกัน)
3. เปิด Developer mode (มุมขวาบน)
4. กด Load unpacked แล้วเลือกโฟลเดอร์ `integrations/web-extension`
5. รีโหลดแท็บ claude.ai / chatgpt.com / gemini.google.com ที่เปิดค้างไว้

## ทดสอบใน monitor mode
1. ตั้ง hwAI เป็น monitor mode
2. เปิด claude.ai พิมพ์อะไรก็ได้แล้วกด Enter
3. จะเห็นป้ายด้านล่างกลางจอ "กำลังบันทึกการใช้ AI…" ไม่เกินประมาณ 3 วินาที แล้วข้อความถูกส่งตามปกติ
4. เปิด popup ของส่วนขยายเพื่อดูสถานะ daemon, โหมด และจำนวนที่ตรวจจับ
5. ใน enforce mode ป้ายจะเป็น "ไหว้กูซะก่อนส่ง…" และข้อความจะถูกกันไว้จนกว่าจะไหว้ผ่าน

## ตรวจจับอะไร / ไม่ตรวจจับอะไร
ตรวจจับ: Enter (ไม่ใช่ Shift+Enter) ใน composer และการคลิกปุ่มส่ง บน 3 เว็บข้างต้น, เฉพาะกรณีที่ช่องพิมพ์ไม่ว่าง และไม่ใช่ระหว่างพิมพ์ IME

ไม่ตรวจจับ: AI อื่นๆ (Perplexity, Copilot, Poe ฯลฯ), แอปเดสก์ท็อปของ Claude/ChatGPT, การเรียก API ตรงๆ, Safari, เบราว์เซอร์ที่ไม่ได้ติดตั้งส่วนขยาย, การส่งด้วยวิธีที่เว็บเปลี่ยนใหม่จนตัวเลือก (selector) ไม่ตรง Claude Code / Codex ตรวจจับโดย CLI hook อยู่แล้ว

## พฤติกรรมความปลอดภัย
- Fail-open: ถ้า daemon ไม่ได้เปิด หรือเชื่อมต่อไม่ได้ ข้อความถูกส่งทันที ไม่มีป้าย ไม่หน่วง
- ไม่กันเกิน 5 นาที: หลังจากนั้นปล่อยส่งเอง
- ปุ่ม "ข้ามชั่วคราว" ใน popup ทำให้ทุกอย่างผ่านทันที

## ความเป็นส่วนตัว
ข้อความที่พิมพ์ไม่ออกจากหน้าเว็บ ส่วนขยายไม่อ่านและไม่ส่งเนื้อหาพรอมต์หรือเนื้อหาหน้า (ตรวจแค่ว่าช่องพิมพ์ไม่ว่างในเครื่อง) ส่งให้ daemon บนเครื่องเท่านั้น: ชื่อเว็บ (เช่น "Claude (เว็บ)"), source, และแฮช SHA-256 สั้นของ `hostname + pathname` ไม่ติดต่อเซิร์ฟเวอร์ภายนอกใดๆ

## ทำไมไม่มี Safari
Safari ต้องห่อส่วนขยายด้วย Xcode (Safari Web Extension) ซึ่งต้องมี Xcode และลงนามแอป ขั้นตอนต่อไปที่ยังไม่ได้ทำ:

```
xcrun safari-web-extension-converter integrations/web-extension
```

จากนั้นเปิดโปรเจกต์ที่ได้ใน Xcode, Run, แล้วเปิดใช้ส่วนขยายใน Safari > Settings > Extensions (อาจต้องเปิด Develop > Allow Unsigned Extensions)

## ข้อจำกัดที่ทราบ
- selector ของแต่ละเว็บอยู่ในอ็อบเจ็กต์ `SITES` ที่ต้นไฟล์ `content.js` ถ้าเว็บเปลี่ยน DOM ส่วนขยายอาจตรวจไม่เจอหรือส่งซ้ำไม่ได้ (จะปล่อยผ่านแทนที่จะค้าง) ให้แก้ selector ที่นั่น
- การส่งซ้ำ (replay) ใช้การคลิกปุ่มส่งของหน้าเว็บเอง ถ้าหาปุ่มไม่เจอจะลองส่ง Enter สังเคราะห์ซึ่งบางเว็บไม่รับ
- ถ้า daemon เก่ายังไม่มีฟิลด์ `monitor` ใน `/wai/status` ป้ายจะแสดงข้อความแบบ monitor
- ยังไม่ได้ทดสอบกับเบราว์เซอร์จริง
